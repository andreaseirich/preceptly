{% trans "Why Preceptly?" %}

{% trans "As a freelance tutor, keeping track of lessons, contracts, and invoices across spreadsheets and paper notes was a constant source of friction." %}

{% trans "Existing tools were either too complex, too expensive, or simply not built with tutors in mind — so Preceptly was created to fill that gap." %}

{% trans "The goal was a focused, no-nonsense application that handles the administrative side of tutoring so that educators can concentrate on what matters: teaching." %}

{% trans "Preceptly is the tool that was missing when it was needed most." %}

{% trans "The developer" %}

{% trans "Preceptly is built and maintained by Andreas Eirich, a freelance software developer based in Ankum, Lower Saxony, Germany." %}

{% trans "Andreas has been working with Python and Django for several years, building web applications with a focus on clarity, reliability, and practical value." %}

{% trans "Preceptly is a tool he would have used himself — and that personal motivation shapes every design and product decision behind it." %}

{% trans "Technology" %}

{% trans "Preceptly is built on Django 5 and Python 3.12, backed by a PostgreSQL database and hosted on Railway." %}

{% trans "All data is stored on servers located in Germany and processed in accordance with the General Data Protection Regulation (GDPR / DSGVO)." %}

{% trans "The technology stack was chosen for its maturity, security track record, and long-term maintainability." %}
