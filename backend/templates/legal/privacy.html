{% trans "Access logs" %}

{% trans "Every call to preceptly.de is recorded in our database: the requested address, the HTTP method, the status code, the processing time, the IP address, the browser identification (user agent), the referring page, a pseudonymous identifier for your session and, if you are logged in, your user account. Requests for static files, the health check and payment webhooks are excluded." %}

{% trans "Purpose: detecting and fending off attacks, troubleshooting, and simple usage statistics. The data is not passed on to third parties and is not used for advertising or profiling." %}

{% trans "Entries older than 30 days are deleted automatically." %}

{% trans "Legal basis: legitimate interest in the secure and reliable operation of the service (Art. 6 para. 1 lit. f GDPR)." %}

{% trans "Video meetings (Meeting Rooms)" %}

{% trans "The Pro plan includes an integrated video meeting function. Camera and microphone access is optional and only activated by the user's explicit action in the browser." %}

{% trans "Video and audio data is transmitted directly between participants (peer-to-peer via WebRTC). No audio or video is stored on Preceptly servers." %}

{% trans "If a direct connection is not possible (for example behind a firewall or on a mobile network), the encrypted media streams are relayed through a relay server (TURN) that we operate ourselves. It is hosted in Germany by Hetzner Online GmbH (Industriestr. 25, 91710 Gunzenhausen). The relay server sees the participants' IP addresses and forwards the encrypted data without being able to decrypt it; it stores no content. The access data for the relay server is generated anew for every meeting page and is valid for eight hours at most." %}

{% trans "The same server also acts as STUN server to establish the connection, so no IP addresses are sent to external STUN providers for this. Apart from technical system messages the server keeps no records; these messages can contain IP addresses of connection attempts, for example from port scans, and are deleted automatically after 30 days." %}

{% trans "Chat messages and whiteboard drawings are passed on through our application server (Railway) and are not stored; they only exist while the room is open. During a meeting the browser also sends a few short technical messages (part of the room identifier, role, type of connection, number of audio and video tracks). They contain no names, IP addresses or content and appear in the application logs at Railway." %}

{% trans "Legal basis: Art. 6 para. 1 lit. b GDPR (performance of contract)." %}

{% trans "AI-assisted lesson plans" %}

{% trans "The Pro plan includes AI-generated lesson plan suggestions. We run the AI model (Qwen 2.5, executed via Ollama) ourselves on our own hardware in Germany. No data is transmitted to external AI providers." %}

{% trans "Transmitted are the subject, grade level, date, duration and status of the lesson and of previous lessons, plus any additional notes and PDF material the tutor provides for the generation. Names, contact details and notes stored in Preceptly are removed beforehand. In additional notes and uploaded PDFs, the student's name, email addresses and phone numbers are masked automatically. Because free text cannot be checked completely, tutors should not enter any further personal data there. Notes and PDF content are used only for the respective generation and are not stored." %}

{% trans "The connection between Preceptly and this computer runs through an end-to-end encrypted private network (WireGuard, provided by Tailscale Inc., Toronto, Canada). If no direct connection is possible, the encrypted traffic may be relayed via Tailscale servers; Tailscale cannot read its content. Canada is covered by an adequacy decision of the EU Commission." %}

{% trans "Legal basis: Art. 6 para. 1 lit. b GDPR (performance of contract)." %}

{% trans "Calendar sync (iCloud)" %}

{% trans "Tutors can optionally connect their own iCloud calendar. Preceptly then copies their lessons into a calendar of their choice (by default the event title contains the student's name; the title can be changed in the settings) and imports events from other calendars they select as blocked times (title, time and description)." %}

{% trans "For this we store the Apple ID and an app-specific password in encrypted form; the regular Apple ID password is never requested. The sync can be paused or disconnected at any time in the settings." %}

{% trans "Recipient is Apple Distribution International Ltd., Hollyhill Industrial Estate, Hollyhill, Cork, Ireland, within the tutor's own iCloud account. Data transfers to the USA are based on the standard contractual clauses of the EU Commission." %}

{% trans "Legal basis: Art. 6 para. 1 lit. b GDPR (performance of contract, at the tutor's request)." %}

{% trans "Calendar import via secret address (Google Calendar)" %}

{% trans "Tutors can optionally enter the secret iCal address of their Google Calendar. Preceptly then retrieves that calendar from Google at regular intervals and takes over its appointments as blocked times, so that no lessons can be booked at those times. Only the title and the time of each appointment are read; descriptions, participants and locations are not." %}

{% trans "The address works like a password: we store it in encrypted form, never display it again and never write it to logs. The import can be paused at any time; removing the calendar also deletes the blocked times that were imported from it." %}

{% trans "Recipient of the retrieval request is Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Ireland, within the tutor's own Google account. Google only receives the request itself (including the IP address of our server); no data about students is sent to Google. Where data is transferred to the USA, this is based on the EU-US Data Privacy Framework or the standard contractual clauses of the EU Commission." %}

{% trans "Appointment titles can contain names of third parties (for example a doctor's appointment). Please keep the titles in the calendar you connect neutral." %}

{% trans "Legal basis: Art. 6 para. 1 lit. b GDPR (performance of contract, at the tutor's request)." %}

{% trans "Calendar subscription link" %}

{% trans "Tutors can optionally switch on a calendar subscription link. Calendar apps such as Google Calendar, Apple Calendar or Outlook then retrieve the tutor's lessons from Preceptly at regular intervals (read-only). For each lesson the calendar contains the time and a title; by default the title is just “Nachhilfe”, and the tutor can choose to include the student's name." %}

{% trans "Everyone who knows the link can read these appointments. The link is therefore secret, is not listed anywhere and can be renewed at any time; the old link then stops working immediately. Our server logs may contain the link as part of the requested address." %}

{% trans "The calendar service the tutor chooses receives the data in the tutor's own account and handles it under its own terms; Preceptly has no influence on that and does not know which service retrieves the link." %}
